# 选题决策｜国内付费原创 V1

> AI 项目比赛稳定版：`competition-v1.0.0`

这是一个面向国内付费短剧原创选题的可交互 Web 产品。它解决的不是“替用户自动写完整剧本”，而是帮助创作者从热点、现实素材或成熟对标作品出发，经过多轮人工确认，得到可以直接讨论的选题方案。

项目严格停在选题层，不进入一卡、全剧架构、分集或正文。

## 当前实现

- A / B 两条完整选题流程
- 每个关键阶段的确认、修改、自定义和换一批
- 用户确认状态自动保存
- 少量候选选题对比
- 轻量后台自检，不使用爆款评分或隐藏裁判公式
- 两条路线统一输出选题汇报卡
- 真实模式与比赛演示 fallback
- 独立 Model Provider / Search Provider 适配层
- OpenAI Responses API 与 Web Search 接口

当前稳定版构建、业务链路及 fallback 测试为 9/9 通过。

## 两条体验入口

### 路线 A：热点 / 现实原创

可以让 AI 联网寻找近期热点，也可以直接输入自己的现实素材。

热点或素材 → 核心炸点 → 付费情绪框架 → 核心情绪回报 → 同轴放大 → 创意升级 → 候选选题 → 统一选题汇报卡。

### 路线 B：已有对标 → 新选题

原则上只需输入作品名。系统会搜索公开资料；遇到同名或多版本时先让用户确认。

作品识别 → 选题级拆解确认 → 对标置换 / 选题升级 → 新方向 → 候选选题 → 统一选题汇报卡。

## 最简单的体验方式：比赛演示模式

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

打开启动信息中显示的网址即可体验。没有配置 API Key 时，系统会自动进入“比赛演示模式”，使用四个回归案例与预置业务数据跑通完整流程，不需要修改代码。

## 启用真实模式

真实模式需要一个服务器端环境变量：

```text
OPENAI_API_KEY=你的_OpenAI_API_Key
```

可以复制 `.env.example` 为 `.env` 后填写。真实模式默认使用可配置的 `gpt-5.6-sol`；A 路线热点搜索与 B 路线作品识别通过独立 Search Provider 完成。

不要把 API Key 写进前端、提交到 GitHub，或添加 `NEXT_PUBLIC_` 前缀。

## 最简单的部署方式：ChatGPT Sites

1. 在 ChatGPT 中打开 Sites。
2. 让 Sites 部署当前项目。
3. 在 Site 的 `More actions → Settings` 中新增服务器端 Secret：`OPENAI_API_KEY`。
4. 先保存私有版本并检查；确认后再选择公开访问范围。

如果不配置 Secret，部署后的页面仍可使用比赛演示模式。
